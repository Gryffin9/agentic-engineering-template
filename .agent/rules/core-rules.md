# Core Agent Rules

1. Follow the task contract.
2. Keep diffs small and reviewable.
3. Do not make unrelated refactors.
4. Preserve existing style and project conventions.
5. Use isolated worktrees for parallel or risky work.
6. Run validation gates before claiming completion.
7. Escalate ambiguity instead of guessing on high-impact behavior.
8. Keep humans in the review loop.
