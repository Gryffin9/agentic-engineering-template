# Task Contract Template

This prose format supports general engineering work. For the small runnable JSON example, use the [executable contract reference](executable-contract.md); the validator does not parse Markdown contracts.

## Goal

Describe the concrete outcome in one or two sentences.

## Context

List the relevant product or engineering background needed to do the task safely.

## In scope

- File or subsystem area 1
- File or subsystem area 2

## Out of scope

- Unrelated refactors
- New dependencies unless approved
- Public API changes unless listed here

## Success criteria

- Observable behavior 1
- Observable behavior 2

## Validation gates

```bash
# exact command 1
# exact command 2
```

## Human review focus

List the parts of the change that deserve close review.
